# MVP Circle Timer

## Цель первой версии

Circle Timer — простой веб-таймер для выполнения последовательности упражнений. Первая версия должна помочь пользователю пройти заранее заданную тренировку от начала до конца, не отвлекаясь на самостоятельный отсчёт времени и переключение между упражнениями.

## Функции первой версии

### Экран подготовки

- Отображение списка упражнений в порядке выполнения.
- Для каждого упражнения указаны название, краткое описание и продолжительность.
- Отображение общей продолжительности тренировки.
- Кнопка запуска тренировки.

### Экран тренировки

- Название текущего упражнения.
- Краткое описание текущего упражнения.
- Круговой индикатор оставшегося времени.
- Числовой отсчёт времени в секундах.
- Номер текущего упражнения и общее количество упражнений.
- Название следующего упражнения, если оно есть.
- Автоматический переход к следующему упражнению после завершения отсчёта.
- Возможность поставить таймер на паузу и продолжить его.
- Возможность начать тренировку заново.

### Завершение тренировки

- Отдельное сообщение об успешном завершении всей последовательности.
- Кнопка повторного запуска тренировки.

## Пользовательский сценарий

1. Пользователь открывает приложение в браузере.
2. Пользователь видит список упражнений, их длительность и общую продолжительность тренировки.
3. Пользователь нажимает кнопку запуска.
4. Приложение показывает первое упражнение и запускает обратный отсчёт.
5. Во время выполнения пользователь видит оставшееся время, описание упражнения и свой прогресс в последовательности.
6. При необходимости пользователь ставит таймер на паузу, а затем продолжает тренировку.
7. По окончании времени приложение автоматически переключается на следующее упражнение.
8. После последнего упражнения приложение показывает экран завершения.
9. Пользователь может запустить тренировку заново.

## Ограничения MVP

- В первой версии используется одна заранее заданная последовательность упражнений.
- Регистрация, профиль пользователя и синхронизация между устройствами не требуются.
- Редактор тренировок и сохранение пользовательских наборов упражнений не входят в MVP.
- История тренировок, статистика, уведомления и интеграции с внешними сервисами не входят в MVP.
- Приложение работает на одной веб-странице без серверной части.

## Критерии готовности

MVP считается готовым, если выполнены все условия:

- Приложение открывается в актуальных версиях Chrome, Firefox и Safari без критических ошибок.
- До запуска видны все упражнения, их длительность и общая продолжительность тренировки.
- Кнопка запуска начинает отсчёт с первого упражнения.
- Название, описание, номер упражнения, числовой таймер и круговой индикатор соответствуют текущему состоянию тренировки.
- Отсчёт уменьшается раз в секунду и не уходит в отрицательные значения.
- После окончания времени текущего упражнения автоматически начинается следующее.
- Пауза останавливает отсчёт, а продолжение возобновляет его с сохранённого значения.
- Перезапуск возвращает тренировку к первому упражнению и исходному времени.
- После последнего упражнения отсчёт прекращается и появляется сообщение о завершении.
- Повторный запуск с экрана завершения начинает тренировку заново.
- Интерфейс остаётся читаемым и управляемым на экранах смартфона и компьютера.
- Все основные действия доступны с клавиатуры, а элементы управления имеют понятные текстовые подписи.
- В консоли браузера нет необработанных ошибок при прохождении основного пользовательского сценария.
